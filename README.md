# AnswerSense: Forms

An AI-assisted Chromium browser extension for supported Google Forms.

## Development Status

**Current phase:** P0 — Repository & Tooling Initialization

Repository structure and development tooling are being established. Application functionality has not been implemented.

## Architecture & Technology

- **Extension:** TypeScript, HTML5, CSS3, Manifest V3, Vite
- **Backend:** Node.js, TypeScript, Zod 4.x
- **Testing:** Vitest, Playwright
- **Tooling:** ESLint, Prettier, npm workspaces

For the settled architecture, see the architecture context document.
